# Aseprite 貝茲鋼筆插件使用說明

在獨立的編輯視窗中繪製貝茲曲線與幾何形狀，產生像素結果，並將可編輯的路徑資料保存在 Aseprite 作品中。

## 安裝與開啟

開啟下載的 `.aseprite-extension` 檔案，在 Aseprite 中完成安裝後重新啟動程式。

開啟 RGB 模式的作品，在圖層／影格儲存格的右鍵選單中使用：

- **貝茲鋼筆：新增路徑…**：開始繪製新的曲線圖層。
- **貝茲鋼筆：編輯此路徑…**：編輯選取圖層中已保存的曲線。

也可以在 Aseprite 的鍵盤快捷鍵設定中，替這兩個命令指定快捷鍵。

中文版與英文版使用相同的插件識別名稱和資料格式。一次安裝一種語言；安裝另一種語言會替換原本的介面，既有曲線資料與自訂名稱可以沿用。

分享原始碼時，請保留 `icons/` 資料夾與其中的 PNG 圖示。插件會使用相對路徑載入圖示。

## 快速開始

1. 開啟 RGB 模式的作品。
2. 在右鍵選單選擇 **貝茲鋼筆：新增路徑…**。
3. 使用 **鋼筆** 畫出曲線，或選擇形狀工具拖曳建立圖形。
4. 設定 **描邊**、**填色**、顏色與線寬。
5. 按 **確認套用**，產生像素結果並保存路徑資料。
6. 將作品儲存為 `.aseprite` 檔案。
7. 日後選取產生的曲線圖層，再使用 **貝茲鋼筆：編輯此路徑…** 繼續修改。

匯出 PNG 或 GIF 得到的是完成的像素畫面。請保留 `.aseprite` 原檔，才能繼續編輯曲線。

## 圖層、路徑與子曲線

一個 Aseprite 圖層中，可以有多個插件 **目前路徑** 選單中的項目。每個項目內，又能包含多條互不連接的子曲線。

- **新增獨立路徑**：在目前路徑選單中新增一個項目。
- **另起一段線**：在目前項目內開始新的、不與原線相連的子曲線。

可以替路徑命名，並調整前後排序，決定圖形之間的覆蓋關係。

同一項目中的子曲線可以有不同的描邊與填色顏色；整體線寬和虛線設定則由該路徑項目共用。

## 鋼筆與錨點操作

### 繪製、接續與連接

使用 **鋼筆** 點擊新增錨點，拖曳則建立控制柄，調整曲率。

點擊開放曲線的端點可繼續延伸，再點擊另一條曲線的端點可將兩段連接。將同一段曲線的起點與終點接起來，就會形成閉合路徑。

按 **Esc** 結束目前的接續狀態；也可以按 **另起一段線**，開始新的子曲線。

### 增加與移除錨點

- **增加錨點**：在線段上插入錨點，保留原本的曲線形狀。
- **移除錨點**：移除點擊的錨點，並重新連接相鄰的錨點。
- **Delete／刪除所選錨點**：刪除選取的錨點，並在刪除位置斷開曲線。

### 選取與移動

使用 **框選** 或 **移動錨點** 工具，在空白處拖曳即可框選錨點。拖曳選取框內部，可一起移動選取的錨點。

**移動錨點** 也可以調整單一錨點與控制柄。調整控制柄時按住 **Alt**，可獨立調整其中一側。

### 縮放與旋轉

選取多個錨點後，使用選取框操作：

- 拖曳邊緣或角落控制點：縮放。
- 拖曳上方旋轉控制點：旋轉。
- **Shift**：等比例縮放，或讓旋轉角度吸附。
- **Ctrl**：以中心為基準縮放。

### 跨路徑選取

在選取工具下，按住 **Shift** 點擊另一個圖形，可以累加選取同一 Aseprite 圖層內、不同路徑項目的圖形。再次 Shift 點選可取消該項目的選取。

共同控制框支援一起移動、縮放與旋轉。顏色、線寬、複製、剪下與刪除等其他操作，仍針對 **目前路徑**。需要單項編輯時，可先從目前路徑選單選定項目。

此功能不會跨選 Aseprite 時間軸中的其他圖層。

### 複製、剪下與貼上

在編輯畫布中選取錨點後：

- **Ctrl+C**：複製所選錨點。
- **Ctrl+X**：剪下所選錨點。
- **Ctrl+V**：貼到目前路徑項目。

選取點之間原有的連接會保留，原本不相連的點不會自動連線。貼上會在目前項目內加入子曲線；若要貼到其他項目，請先選取或新增該項目。

Aseprite 未關閉期間，也能跨作品複製與貼上。這是插件內部的曲線剪貼簿，不是系統剪貼簿，也不是 SVG 匯入功能。

## 形狀工具

選取工具後，在畫布上拖曳建立形狀：

| 工具 | 操作與設定 |
| --- | --- |
| 直線 | 拖曳決定兩端；Shift 限制為 45 度方向間隔。 |
| 長方形 | 拖出矩形；Shift 保持正方形。 |
| 圓形 | 拖出橢圓；Shift 保持正圓。 |
| 三角形 | 在拖曳範圍內建立；Shift 保持等比例。 |
| 多邊形 | 建立前設定角數；Shift 保持等比例。 |
| 星形 | 建立前設定角數與深度百分比；深度越大，凹入越深。 |

建立後的形狀會轉成可編輯的貝茲錨點。若要改原始角數或星形深度，請復原後重新建立。

### 圓角

建立形狀前設定 **圓角半徑 px**，可替適用的直線轉角加入圓角。半徑為 0 時保留尖角。

鋼筆路徑也可以選取直線交接的尖角，再按 **所選尖角套用圓角**。已有曲線控制柄的轉角與線段端點不適用。

圓角會實際改變錨點與控制柄，不是保留原始形狀的參數效果。直線沿用圓頭描邊；圓形使用三次貝茲曲線近似橢圓。

## 描邊、填色與線寬

勾選 **描邊** 或 **填色**，會顯示對應設定。

選取錨點後改色，會修改這些錨點所在子曲線的顏色；沒有選取錨點時，則修改路徑預設色。

- **整體線寬 px**：控制目前路徑項目的共用線寬。
- **此錨點線寬 %**：調整單一錨點位置的相對線寬。
- **實線／虛線**：虛線由四段長度組成，順序為空白、實線、空白、實線。

自訂筆刷尚未實作。

## 鏡像

可建立水平或垂直鏡像，並選擇是否保留原曲線，以及是否持續連動。

**連動鏡像** 會跟隨來源路徑更新。若想獨立修改鏡像，請先 **解除連動**；也可以使用 **編輯原曲線** 回到來源。

鏡像基準可選作品中心、路徑中心或自訂中線。自訂中線設定影響新建立的鏡像。

## 多幀與動畫

曲線資料依影格保存。**複製前一幀** 會將前一幀的曲線載入目前編輯器，**確認套用** 只修改開啟編輯器時的影格。

切換或重新排列時間軸影格前，請先完成或取消編輯，再於目標影格重新開啟插件。

以眨眼動畫為例：

1. 在第一幀完成並套用睜眼的曲線。
2. 在 Aseprite 選取下一幀，於曲線圖層開啟編輯器。
3. 使用 **複製前一幀** 帶入曲線。
4. 選取眼睛路徑，縮小高度，再微調錨點。
5. 確認套用，依序製作其他姿勢。

每一幀的姿勢仍需手動調整，插件不會自動產生中間幀。

## 作品尺寸改變

作品尺寸與已保存曲線尺寸不同時，重新編輯路徑會出現尺寸處理視窗。

- **依新尺寸縮放**：依新舊尺寸比例調整路徑，可選擇一起縮放線寬。
- **只平移（保留曲線尺寸）**：保留曲線大小、控制柄與線寬，只調整位置。

九宮格指定新舊畫布的對齊位置，預設為中央。**額外 X／Y** 滑桿用於微調，也可以直接輸入數值。正 X 向右，正 Y 向下。

例如畫布寬度從 100 改為 160，中央對齊會向右平移 30 px；再設定額外 X 為 5，總位移就是 35 px。

### 尺寸預覽

- **藍色輪廓**：顯示曲線，包括作品畫布外的部分。
- **黃色外框**：標示全部曲線範圍；只平移模式下可直接拖曳框內部移動曲線，同步更新 X／Y。
- **顯示作品與曲線**：將作品和曲線一起放進預覽範圍。
- **適合視窗**：顯示整張作品。
- **預覽縮放 %／100%／滾輪**：調整檢視倍率。
- **中鍵拖曳／空白鍵＋左鍵拖曳**：移動預覽視角。

預覽縮放與視角移動不會改動路徑。黃色外框用來定位與平移，不是縮放控制框。

**繼續編輯** 只將調整結果帶入編輯器；最後按 **確認套用** 才會寫回目前影格。取消不會修改已保存的路徑。不同影格在日後開啟時，會各自處理尺寸差異。

## 偏好設定與自動備份

在 **偏好設定** 中，可以調整縮放、線寬、錨點與路徑數量等編輯上限，並設定是否開啟自動備份與備份間隔的分鐘、秒數。

自動備份保存的是尚未套用的曲線草稿，位置在 Aseprite 使用者設定資料夾中，不會代替完整作品存檔。

使用 **載入自動備份…** 選擇草稿，確認內容後再套用。請仍正常儲存 `.aseprite` 作品，以保存已套用的像素與路徑資料。

## 注意事項

- 插件以向量路徑編輯，套用到 Aseprite 的結果仍是像素，不是原生向量圖層或 SVG。
- 編輯需要 RGB 模式。
- 跨路徑多選的共同變形，不等於所有設定都支援批次修改。
- 大量錨點、粗線與極高倍率可能增加運算時間。
- 預覽輪廓、錨點與選取框不會出現在套用結果中。
