# 貝茲鋼筆 0.1.1｜繁體中文測試版

在獨立路徑視窗中編輯錨點和控制柄，拖動時立即更新预覽；按確認才套用到作品。每條路徑各自保存在一個圖層，之後可繼續修改。

目標版本：Aseprite 1.3.18.3 x64。第一版支援 RGB、單幀作品。

## 安裝與開啟

1. Edit → Preferences → Extensions → Add Extension，選擇 `bezier-pen-0.1.1.aseprite-extension`。
2. 安裝後重新啟動 Aseprite。這是獨立插件，不會取代黑白遮罩插件。
3. 建立或開啟 RGB、單幀作品。
4. 在時間軸的影格格子上按右鍵，選 **「貝茲鋼筆：新增路徑…」**。

兩個命令也可以在 Aseprite 的鍵盤快捷鍵設定中搜尋並指定快捷鍵。

## 像鋼筆一樣建立曲線

- 在預覽區空白位置點一下：建立錨點。依點擊順序連成路徑。
- 在空白位置按住並拖動：建立錨點並拉出左右控制柄。
- 拖曳白色／黃色錨點：移動錨點，兩側控制柄跟著移動。
- 點選錨點後，拖橘色控制柄：改變該側的曲率。
- 勾選「控制柄平滑連動」：兩柄方向保持共線，兩侧長度可以不同。
- 取消勾選，或按住 **Alt 拖柄**：兩側獨立調整；Alt 操作會將該點切成獨立模式。
- 「建立控制柄」可為沒有控制柄的點建立左右柄。
- 「轉為尖角」把該點的柄縮回錨點，可再使用「建立控制柄」。

「選取：只移動」模式可以避免點空白處時意外新增錨點。每條路徑最多 256 個錨點；至少兩個點才能套用。第一版可以新增至路徑末端及刪除錨點，尚未提供在既有曲線中間插點。

## 粗細與顏色

- **整體線寬 px**：1–128 像素。
- **顏色**：可設定 RGB 與透明度。
- **此錨點線寬 %**：選錨點後設定 0–1000%，曲線會在相鄰錨點之間漸變粗細。
  - 每點 100%：整條保持相同粗細。
  - 起點 0%、終點 100%：由尖細逐漸變粗。
  - 中間點 200%：中段可加粗。
- **閉合路徑**：將最後一點連回第一點，至少三個錨點。第一版提供描邊，不提供內部填色。

輸出是無反鋸齒的像素線條，不是向量圖層。預覽與套用使用同一套像素計算，半透明色不會因重疊取樣越疊越深。圓頭線端與像素格排列可能造成局部鋸齒，這不是平滑向量輸出。

## 預覽操作

- 滾輪縮放，中鍵拖曳平移；「縮放還原」回到整張作品。
- 「顯示作品參考」顯示開啟編輯器當下的作品，方便對準。編輯既有路徑時，參考圖會排除該路徑的舊影像。
- 「顯示錨點與控制柄」可切換藍色路徑骨架、錨點和控制柄。藍色骨架只是編輯提示，不會套用到作品。
- 「復原路徑／重做路徑」只操作編輯器內的草稿；最多保存 64 次編輯狀態。拖曳一次算一次操作；線寬滑桿的連續變動可能有多個步驟。
- 當預覽區有焦點時，Ctrl+Z 復原路徑、Ctrl+Shift+Z 或 Ctrl+Y 重做。

視窗可調整大小。預覽使用編輯視窗自己的滑鼠移動事件，因此會在控制柄／錨點拖曳期間重新計算，不依賴主畫布放開筆之後的變更事件。大圖、很粗或很長的線仍可能較慢。

## 確認、保存、再修改

1. 下方輸入路徑名稱，按 **「確認套用」**。新增路徑會建立一個獨立圖層，不修改其他圖層。
2. 按「取消」或關閉視窗會捨棄尚未確認的路徑修改，作品保持原狀。
3. 用 **`.aseprite`** 格式保存作品。圖層中會一併保存錨點、控制柄、線寬、每點線寬比例、顏色及閉合設定。
4. 之後選取那條曲線所在的圖層，時間軸格子右鍵 → **「貝茲鋼筆：編輯此路徑…」**。
5. 修改後確認，更新同一個路徑圖層。作品中的原生復原可以撤回這次套用，包括圖像與路徑資料。

多條曲線就是多個路徑圖層，可各自命名與編輯。示範檔 `貝茲曲線範例.aseprite` 內含已保存的路徑。

## 本版限制

- 路徑資料是插件保存的模型，不是 Aseprite 原生向量路徑。PNG 不會保存錨點。
- 請用本插件修改曲線。直接用普通畫筆修路徑圖層後，再由插件套用時，那些手繪修正會被重新產生的曲線取代。
- 直接移動／旋轉／縮放路徑圖層不會修改已記錄的錨點；重新套用會回到記錄的位置。改作品尺寸後，本版會拒絕重新編輯尺寸不符的路徑，尚未實作路徑自動縮放。
- 作品參考圖是開啟時的快照，不會跟著其他視窗中的修改即時更新。建議編輯完確認／取消後再改主作品。
- 預覽未模擬既有路徑圖層的特殊混合模式、父群組效果或圖層不透明度；使用普通模式與 100% 圖層不透明度時較容易直接對照。
- 不支援動畫、索引色、壓力筆刷、布林路徑或向量檔輸出。

## 驗證狀態

已用本機 Aseprite 批次模式驗證貝茲取樣、線寬、透明度、控制柄獨立／連動、漸變粗細、各路徑保存與重開、套用復原／重做。
滑鼠按下／移動／放開與按鈕回呼，已以模擬視窗搭配真實 Aseprite 影像測試，包含放開前更新、預覽等於套用、取消不寫入作品及重新編輯同一層。實際 GUI 排版與拖曳手感尚需試用確認。

## 0.1.1 更新
錨點線寬比例上限由 200% 提高到 1000%，並依實際線寬擴大輸出範圍，避免加粗被裁切。整體線寬仍為 1–128 px；例如整體 20 px、錨點 1000%，該點線寬就是 200 px。已驗證粗線範圍、保存重開及既有編輯功能。
